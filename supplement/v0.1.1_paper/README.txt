The supplied PDF and final_content.json share the audited manuscript content.
kaggle_writeup.txt uses Markdown headings and contiguous tables for pasting into
the Kaggle Writeup editor. The word limit is checked conservatively with the
references and table text included. See validation and the final render receipt.

verify_numbers.py verifies task/project/check denominators, the complete32 main
records, all per-task acceptance cells, accepted source identities and reported
main API cost against the released raw response receipts. It makes no API or
Docker request. Free patch replay is provided at the distribution root.

render.py is an optional portable content renderer using standard Times fonts.
It does not recalculate experimental results or regenerate an oracle. Exact
pagination, embedded fonts and PDF bytes can differ from the supplied PDF.
